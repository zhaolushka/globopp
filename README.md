# Сайт активностей и дедлайнов + уведомления в Telegram

Что это: публичная страница со списком активностей и дедлайнов, админка для
их добавления, и Telegram-бот, который раз в день рассылает напоминания
всем подписавшимся ученикам.

Стек: Next.js + Supabase (база данных) + Telegram Bot API + Vercel (хостинг + бесплатный cron).
Всё бесплатно на масштабе 30-200 учеников.

---

## Шаг 0. Что понадобится

- Аккаунт на [github.com](https://github.com) (бесплатно)
- Аккаунт на [vercel.com](https://vercel.com) — регистрируйся через GitHub
- Аккаунт на [supabase.com](https://supabase.com) — регистрируйся через GitHub
- Telegram
- Node.js установлен на компьютере (для локальной проверки) — [nodejs.org](https://nodejs.org)

---

## Шаг 1. Создать Telegram-бота

1. Открой Telegram, найди **@BotFather**
2. Напиши `/newbot`
3. Придумай имя (любое) и username бота — он должен заканчиваться на `bot`, например `myschool_deadlines_bot`
4. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его, он понадобится
5. Запомни username бота (без @) — он тоже понадобится

---

## Шаг 2. Создать базу данных в Supabase

1. Зайди на [supabase.com](https://supabase.com) → New Project
2. Придумай пароль для базы (просто сохрани куда-нибудь, он не используется напрямую в этом проекте)
3. Дождись создания проекта (~2 минуты)
4. Слева зайди в **SQL Editor** → New query
5. Открой файл `supabase-schema.sql` из этого проекта, скопируй всё содержимое, вставь и нажми **Run**
   — это создаст таблицы `activities` и `subscribers`
6. Зайди в **Settings → API**. Тебе понадобятся три значения:
   - `Project URL` → это `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public` key → это `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role` key (секретный, не путай с anon!) → это `SUPABASE_SERVICE_ROLE_KEY`

---

## Шаг 3. Настроить переменные окружения

1. В папке проекта скопируй `.env.local.example` в новый файл `.env.local`
2. Заполни все значения:
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` — из Шага 2
   - `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` — из Шага 1
   - `ADMIN_PASSWORD` — придумай любой пароль для входа в админку
   - `CRON_SECRET` — придумай длинную случайную строку (например, сгенерируй на [1password.com/password-generator](https://1password.com/password-generator))

---

## Шаг 4. Проверить локально (необязательно, но полезно)

```bash
npm install
npm run dev
```

Открой `http://localhost:3000` — должна открыться пустая страница активностей.
`http://localhost:3000/admin` — вход в админку по паролю из `.env.local`.

(Вебхук Telegram и рассылка локально работать не будут — Telegram не может
достучаться до `localhost`. Это нормально, проверим после деплоя.)

---

## Шаг 5. Выложить на Vercel

1. Залей проект на GitHub (создай новый репозиторий и запушь код)
2. Зайди на [vercel.com](https://vercel.com) → **Add New Project** → выбери свой репозиторий
3. На экране настройки проекта разверни **Environment Variables** и добавь
   ВСЕ переменные из своего `.env.local` (те же имена и значения)
4. Нажми **Deploy**
5. После деплоя Vercel даст тебе адрес вида `https://твой-проект.vercel.app`

---

## Шаг 6. Подключить Telegram-бота к сайту

Telegram должен знать, куда слать сообщения от пользователей бота. Выполни
этот запрос один раз (замени данные на свои) — можно прямо в адресной строке браузера:

```
https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/setWebhook?url=https://твой-проект.vercel.app/api/telegram-webhook
```

Если всё ок, увидишь `{"ok":true,"result":true,...}`.

Теперь зайди в своего бота в Telegram и нажми **Start** (или напиши `/start`) —
должно прийти сообщение о подписке. Проверь в Supabase (Table Editor →
subscribers), что твой chat_id появился в таблице.

---

## Шаг 7. Проверить рассылку

Cron в `vercel.json` настроен на запуск каждый день в 06:00 UTC (поменяй
`schedule` в `vercel.json`, если нужно другое время — учти, что это UTC,
не твой часовой пояс).

Проверить вручную можно так (замени на свои значения):

```
https://твой-проект.vercel.app/api/cron/send-reminders?secret=ТВОЙ_CRON_SECRET
```

Если есть активности, у которых подошло время напоминания — сообщения
разлетятся подписчикам, и в ответе будет `remindersSent` со списком.

---

## Шаг 8. Добавить активности

Зайди на `https://твой-проект.vercel.app/admin`, введи `ADMIN_PASSWORD`,
и добавляй активности: название, описание, дедлайн, за сколько дней
напомнить.

---

## Как это работает вкратце

- **`pages/index.js`** — публичная страница со списком активностей (читает Supabase напрямую)
- **`pages/admin.js`** + **`pages/api/activities.js`** — админка (CRUD, защищена паролем в заголовке запроса)
- **`pages/api/telegram-webhook.js`** — принимает сообщения от бота (`/start` → подписка, `/stop` → отписка)
- **`pages/api/cron/send-reminders.js`** — раз в день проверяет, у каких активностей подошло время напоминания, и рассылает всем подписчикам
- **`vercel.json`** — расписание крона

## Что можно улучшить потом

- Разные напоминания для разных классов/групп (сейчас рассылка идёт всем подписчикам разом)
- Кнопки в Telegram-сообщении ("отметить как выполнено")
- Логин учеников по имени, а не просто подписка на бота
- Часовой пояс — сейчас даты хранятся в UTC, показываются в локальном времени браузера
